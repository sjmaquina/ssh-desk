# Changelog

## 0.1.0 — initial release

- MIT license and an Omarchy Quattro bar widget that launches the TUI.

- Encrypted connection profiles and master password changes.
- Separate OpenSSH terminal windows, pinned host keys, and automatic reconnects.
- Session CPU/RAM telemetry and received/sent terminal-data counters.
- Retro ASCII branding, six saved palettes, responsive tables, and keyboard controls.
- Active-session filtering and individual or profile-wide session closing.
- User-local installer, desktop launcher, and support for common Linux terminals.
